# Detailed Prompt — Premium Digital Producer Portfolio Website

Create a **modern, premium, highly interactive personal portfolio website for a Digital Producer / AI & Web Developer**.

The website should feel like a combination of:

- Digital production studio
- Creative technology portfolio
- AI engineer portfolio
- Professional personal brand
- Modern startup landing page

The design must be **clean, sophisticated, minimal, highly responsive, and visually impressive**, without looking like a generic developer template.

---

## 1. Personal Brand

Use the following positioning:

**Name:** John Doe

**Primary Title:**
Digital Producer • AI Developer • Full-Stack Web Developer

**Short tagline:**

> I turn ideas into digital products, intelligent experiences, and scalable web solutions.

Alternative supporting line:

> From concept to launch — combining AI, design, development, and digital strategy to build products that actually work.

The portfolio should communicate that the person is not only a programmer but a **digital producer who can take a project from an idea to a finished product**.

---

# 2. Overall Design Direction

Use a premium technology-focused visual identity.

### Style

- Minimal
- Modern
- Futuristic but professional
- Creative
- Editorial
- High-end agency aesthetic
- Subtle glassmorphism
- Soft gradients
- Large typography
- Generous whitespace
- Smooth animations
- Strong visual hierarchy

Avoid:

- Generic portfolio templates
- Excessive glowing effects
- Too many gradients
- Excessive cards
- Cartoonish UI
- Overly complicated animations
- Cluttered layouts

The website should look like it belongs to a **high-end digital product studio**.

# 26. Responsive Design

The website must work perfectly on:

- Desktop
- Laptop
- Tablet
- Mobile

Mobile design must NOT simply shrink the desktop layout.

For mobile:

- Stack sections
- Use large readable typography
- Make buttons full-width where appropriate
- Convert horizontal timelines to vertical
- Optimize images
- Use hamburger navigation
- Maintain smooth animations without hurting performance
